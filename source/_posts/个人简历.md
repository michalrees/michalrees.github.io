## 项目与著作

### klimapy · 作者与维护者

`Python` `PyPI` `开源`

- 面向气候数据分析的开源 Python 工具包，提供 **ETCCDI 极端气候指数** 计算与 **BCSD 统计降尺度** 模块
- 发布于 PyPI，首个版本 `1.0.0`（2026-04-20）
- 依赖 numpy / pandas / xarray / tqdm / cftime
- 源码：[github.com/michalrees/klimapy](https://github.com/michalrees/klimapy) ｜ 安装：`pip install klimapy`
